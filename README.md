# 신사업 제안 — 예약 기반 서비스업의 실시간 빈 슬롯 마켓플레이스

> **한 줄 정의**
> **"지금, 내가 갈 수 있는 거리 안에서, 비어 있는 예약 한 자리를 채운다."**

소상공인의 **비어버린 예약 슬롯**과 사용자의 **비어버린 시간**을 서로 채워주는,
위치 · 시간 · **이동수단** 기반 실시간 예약 마켓플레이스.

> **서비스명: 넛츠 (NUTS)** — '심심풀이 땅콩'에서 왔습니다. 심심한 시간에, 한 줌, 가볍게.
> 이름의 근거와 검토 과정 → [docs/05_naming.md](docs/05_naming.md) · 로고 → [brand/](brand/)

---

## 핵심 주장 두 가지

**① 이 조합이 시장에 없습니다.** 인접한 세 서비스는 전부 존재하는데 합쳐진 자리만 비어 있습니다.

| | 무엇을 파나 | 언제 파나 | 왜 여기로 못 오나 |
|---|---|---|---|
| 마감히어로 · 라스트오더 | 음식 | 오늘 | **물건 재고**를 세는 구조라 예약 슬롯으로 못 넘어옴 |
| 당근 | 중고 물건 | 상시 · 내 주변 | 거래 대상이 물건이고 사업자 재고가 아님 |
| 네이버예약 · 카카오헤어샵 | 서비스업 | **내일 · 다음 주** | **정가**로 수익을 내므로 스스로 할인을 걸 수 없음 |
| **본 제안** | **서비스업** | **지금 · 내 주변** | — |

**② 도달 가능성을 정렬이 아니라 필터로 씁니다.** 기존 앱은 거리순으로 보여주고 도착 가능 여부는 사용자가 계산합니다. 본 서비스는 **도보 / 자전거 / 차량**을 고르게 하고 **마감까지 남은 시간 안에 실제로 도착 가능한 슬롯만** 노출합니다.

```
현재시각 + 이동시간(수단, 거리) + 준비버퍼  ≤  예약 마감시각
        → 참이면 노출 / 거짓이면 화면에서 숨김
```

같은 시각 같은 자리에 서 있어도 **이동수단에 따라 다른 화면**을 봅니다.

## 요약

**확장 4단계** — 단계마다 새로 배우는 역량이 딱 하나씩만 늘어나도록 순서를 잡았습니다.

| 단계 | 업종 | 새로 배우는 역량 |
|---|---|---|
| 1 | 미용실 · 네일 · 마사지 | (기반) 1:1 슬롯 매칭 · 도달 엔진 · 선결제 |
| 2 | 연극 · 영화 · 방탈출 · 보드게임 | **수량 재고와 동시성 제어** |
| 3 | 숙박 | **분리된 시간 재고** (마감이 '몇 분 안에' → '오늘 자정까지') |
| 4 | 포장음식 (만두 · 빵 · 과일가게) | **실시간 물리재고 · 신선도** |

1 · 4단계는 소상공인이 **밀도**를, 2 · 3단계는 대기업이 **규모**를 만듭니다. 대형 체인은 트래픽을 증명한 플랫폼에만 재고를 열기 때문에 **순서를 바꿀 수 없습니다.**

**운영 3원칙** — ① 강남구 단일 런칭 ② 선결제 의무 ③ 그 가게의 단골에게는 할인 슬롯을 숨김(신규 고객 채널로 유지)

**재무 (추정, 억 원)** — 수수료는 첫날부터 10%, 첫 3개월만 무료

| | 1년차 | 2년차 | 3년차 | 4년차 |
|---|---|---|---|---|
| 거래액 | 5 | 43 | 202 | 576 |
| 매출 | 0.3 | 4.1 | 22.2 | 74.9 |
| 영업손익 | -4.7 | -8.1 | **+2.2** | +39.9 |

연 단위 흑자 **3년차**, 필요 투자 약 **13억**, 회수 **4년차 상반기**.
근거와 흔들릴 수 있는 지점 3가지는 [docs/01_business-model.md](docs/01_business-model.md) §7 참조.

## Word 파일 재생성

문구나 수치를 고친 뒤 다시 뽑을 때:

```bash
npm install
npm run build          # 제안서 + 발표대본 둘 다
```

발표 대본은 [docs/04_presentation-script.md](docs/04_presentation-script.md)가 원본이고,
`docs/gen-script-blocks.py`가 이를 읽어 두 Word 빌더에 들어갈 블록을 생성합니다.
**대본은 markdown 한 곳만 고치면 됩니다.**
