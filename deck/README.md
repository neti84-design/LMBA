# 발표자료 생성 스크립트

```bash
npm install pptxgenjs
node build.js                                   # 기본 — Pretendard
python3 verify.py                               # 도형 겹침·화면 밖 검사
FONT=malgun OUT=LGA_롯데신사업_발표_맑은고딕.pptx node build.js   # 안전 글꼴 버전
```

PDF로 뽑으려면 (글꼴이 파일 안에 박혀서 어느 PC에서나 똑같이 보입니다):

```bash
soffice --headless --convert-to pdf LGA_롯데신사업_발표.pptx
```

> LibreOffice로 변환할 때는 **그 PC에 Pretendard가 설치돼 있어야** 합니다.
> 없으면 글꼴이 대체되면서 PDF의 줄바꿈이 PPT와 달라집니다.

| 파일 | 역할 |
|---|---|
| `build.js` | 슬라이드 18장(본편 14 + 백업 4)의 내용과 배치 — IR 덱 표준 9블록 순서 |
| `design.js` | **디자인 시스템** — 글꼴·타입 스케일·줄간격·그리드·자동 높이·넘침 검사 |
| `notes.js` | 발표 대본 18개 (본편 600초 + 백업). 슬라이드 노트로 삽입됩니다 |

## 글꼴

`FONT` 환경변수 하나로 바뀝니다. 기본값은 **Pretendard**입니다.

> ⚠️ **Pretendard는 발표할 PC에 설치돼 있어야 합니다.** 없으면 PowerPoint가 다른 글꼴로
> 대체하면서 줄바꿈이 전부 틀어집니다. 발표 PC가 확실하지 않으면
> 저장소에 함께 들어 있는 **`LGA_롯데신사업_발표_맑은고딕.pptx`** 를 쓰십시오.
> (맑은 고딕은 모든 Windows에 기본 설치)

| 값 | 글꼴 |
|---|---|
| (기본) | Pretendard |
| `FONT=malgun` | 맑은 고딕 — 어디서나 안전 |
| `FONT=nanum` | 나눔스퀘어 |

## 디자인 시스템 (`design.js`)

문구를 고쳐도 레이아웃이 깨지지 않도록 **높이를 내용에서 계산**합니다.

- **타입 스케일 8단계** — `micro 10 / tag 11 / small 11.5 / body 13 / lead 15 / h3 18 / h2 26 / hero 62`.
  이 밖의 크기는 쓰지 않습니다.
- **줄간격은 계산값** — 본문 `LH(s) = s × 1.5`, 큰 글자 `LHt(s) = s × 1.2`. 직접 지정하지 않습니다.
- **그리드** — 좌우 여백 0.62", 본문 폭 12.09", 본문 영역 y 1.62 → 6.70 (하단 문장이 있으면 6.50).
  열은 `cols(n)` / `colX(i,n)` 으로만 잡습니다.
- **자동 높이** — `tx()` 와 `cardRow()` 가 글자폭을 추정해 줄 수를 세고 박스 높이를 정합니다.
  한 줄에 놓인 카드는 **가장 높은 카드에 맞춰 전부 같은 높이**가 됩니다.
- **세로 채움** — `spread()` 가 남는 공간을 블록에 나눠 줘서 아래쪽이 비지 않습니다.
- **검사 2종** — 둘 다 통과해야 정상입니다.
  - `node build.js` → **글자가 박스를 넘치는지** + **블록 합계가 배정 공간을 넘는지(= 아래 요소와 겹침)**.
    `레이아웃 점검: 넘치는 텍스트 없음`
  - `python3 verify.py` → **도형끼리 겹치는지 / 화면 밖으로 나갔는지** 를 만들어진 파일에서 직접 검사.
    `도형 점검: 문제 없음`
- **카드 성장 상한** — 남는 공간을 나눠 줄 때 자연 높이의 1.35배까지만 키웁니다.
  더 키우면 글자는 위에 몰리고 아래가 텅 빕니다. 늘어난 카드의 내용은 한 줄 전체가 같은 만큼
  내려와서 제목 기준선은 그대로 유지됩니다.

## 구성

- 본편 14장 = First page · Problem ×2 · Solution ×2 · Market ×2 · Business models ×2 · Traction ×2 · Team · Ask · Last page
- 백업 4장 = B1 숫자의 근거 · B2 프라이버시 2계층 + 핵심가치 · B3 리스크 · B4 원가 구조
- 칩 번호 01~07은 IR 블록 번호(Problem=01 … Ask=07), 우측 상단에 블록 이름
- 네이티브 차트 3개(5·10·18번) — PowerPoint에서 데이터 수정이 그대로 됩니다
- 6번(Market ①)의 TAM·SAM·SOM 입력값은 `MKT` 배열과 바로 아래 각주 두 곳에 있습니다 — 함께 고치십시오
- 대본을 고치면 `notes.js` 의 `(N초)` 표기도 함께 고치고 `docs/04_pitch-10min.md` 를 재생성하십시오
