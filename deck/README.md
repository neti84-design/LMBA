# 발표자료 생성 스크립트

`../LGA_롯데신사업_발표.pptx` 를 만드는 pptxgenjs 스크립트입니다.
문구나 수치를 고친 뒤 다시 돌리면 PPT가 재생성됩니다.

```bash
npm install pptxgenjs
node build.js
```

## 구성

- 15장 = 타이틀 · BMC 개요 · 9블록(02·05는 2장씩) · 클로징 + 백업 1장(리스크)
- 순서: Step 1 가치 전달(01~05, 빨간 칩) → Step 2 효율적 운영(06~09, 검은 칩)
- **모든 슬라이드에 발표 대본이 슬라이드 노트로 들어가 있습니다.** PowerPoint 발표자 보기에서 확인하세요.
- 본문 폰트: 맑은 고딕. 다른 폰트로 바꾸려면 `const F = "맑은 고딕"` 한 줄만 수정하면 됩니다.
- 네이티브 차트 3개(5·9·13번)라 PowerPoint에서 데이터 수정이 그대로 됩니다.
