# 08. 전지 작성안 — 「롯데마트의 유일한 가치」와 「활동의 정합성」

> **용도**: 워크숍 전지(788×1091mm) 손글씨 작성용.
> **다루는 질문 2개**
> 1. 롯데마트의 유니크한 가치는 무엇인가? 경쟁자 대비 **유일하게** 제공할 수 있는 것은?
> 2. 그 약속한 가치를 남들보다 잘 제공하기 위해 **모든 활동이 일관되게** 구성되어 있는가?
>
> 이 두 질문은 마이클 포터의 「전략이란 무엇인가」의 두 축입니다.
> 질문 1 = **고유한 가치제안(Unique Value Proposition)**, 질문 2 = **활동 간 적합성(Fit)**.
> 그래서 전지도 **1장 = 가치, 2장 = 정합성** 두 장으로 나누어 쓰는 것을 권합니다.
> (1장만 써야 할 경우는 §5 축약본 참조)

## 1-3. 블록 [B] — 경쟁자 지도 (카드 5개)

각 카드는 가로 긴 직사각형. **"유일하게 주는 것 / 구조적으로 못 주는 것"** 2칸으로.

```
┌──────────────────────────────────────────────┐
│ 쿠팡        속도·최저가·검색의 편의            │
│            ✕ 술 배송 불가 · 발견·시식 불가     │
├──────────────────────────────────────────────┤
│ 컬리        프리미엄 신선 큐레이션              │
│            ✕ 술 배송 불가 · 가격 · 오늘 당장   │
├──────────────────────────────────────────────┤
│ 이마트      브랜드 신뢰 · 트레이더스 · 노브랜드  │
│            ✕ 주류 제조·수입 계열사 없음        │
├──────────────────────────────────────────────┤
│ 홈플러스    메가푸드마켓 · 가격                 │
│            ✕ 투자 여력(대주주 구조)           │
├──────────────────────────────────────────────┤
│ 코스트코    회원제 대량 · 글로벌 PB             │
│            ✕ 점포 접근성 · 소량·한국형 구색     │
└──────────────────────────────────────────────┘
```

> `[말로] — 이 표에서 가장 중요한 줄은 맨 위 두 개입니다.`
> **주류는 온라인이 구조적으로 못 파는 카테고리입니다.**
> 국내법상 일반 주류의 통신판매(택배 배송)는 금지되어 있고,
> 예외는 전통주와 **스마트오더(온라인 결제 후 매장 픽업)** 뿐입니다.
> 즉 쿠팡이 아무리 커져도 와인·위스키·맥주를 집앞으로 보낼 수 없습니다.
> **대형마트에 남은 마지막 구조적 방어 카테고리가 술입니다.**
> 그리고 그 카테고리에서 롯데는 국내 최대급 주류 수입·유통사(롯데칠성)를 그룹 안에 갖고 있습니다.
> — 이 두 문장이 오늘 발표의 전부입니다. `[수치·순위는 발표 전 확인필요]`

## 2-2. 블록 [B] — 활동 체계도 그리는 법

포터의 활동체계도(Activity System Map) 형식입니다. **원 + 화살표**로만 그립니다.

```
그리는 순서
① 중앙에 지름 20cm 원 — 빨강 테두리 — 여기에 "약속"을 쓴다
② 그 둘레에 지름 11cm 원 6개 — 파랑 테두리 — 시계 2·4·6·8·10·12시 방향
③ 중앙↔위성을 실선으로 연결
④ 위성↔위성 중 서로 강화하는 쌍만 점선으로 연결  ← 이게 "Fit"의 증거
⑤ 서로 상충하는 쌍은 빨간 X 표시를 선 위에 그린다  ← 이게 "어긋남"
```

원 안에 쓸 글자 (짧게!):

```
        중앙(빨강)  :  술·먹거리가 가장 깊은 마트

        12시  상품 소싱   : 마트·슈퍼 통합구매 / 칠성 주류 / 해외 직소싱
         2시  PB         : 요리하다(먹거리) · 오늘좋은(생활)
         4시  매장 포맷   : 제타플렉스 · 보틀벙커 · 그로서리 리뉴얼
         6시  사람       : 와인·정육·델리 전문인력
         8시  데이터     : L.POINT 취향 → 발주·PB 개발로 되먹임
        10시  온라인     : 바로배송 / 스마트오더 픽업 (보완재)

   점선(서로 강화) : 12시 ↔ 2시  (소싱 규모 → PB 원가)
                    12시 ↔ 4시  (칠성 포트폴리오 → 보틀벙커)
                     4시 ↔ 6시  (발견형 매장 → 전문인력 필요)
                     8시 ↔ 2시  (취향 데이터 → PB 기획)

   빨간 X(상충)   :  4시 ↔ "최저가 캠페인"  (깊이 vs 가격, 같이 못 감)
                    10시 ↔ 중앙            (온라인이 그로서리 가치를 못 나름)
```

## 2-3. 블록 [C] — 정합성 신호등

전지에 쓸 것:

```
○ 맞물려 있다
  1 마트+슈퍼 구매 통합      → 바잉파워·PB 물량
  2 PB 2종 정리(요리하다·오늘좋은) → 그로서리 초점과 일치
  3 보틀벙커 ← 칠성 소싱     → 강화의 모범 사례 ★
  4 제타플렉스 그로서리 확대   → 약속과 일치

△ 절반만 맞는다
  5 전문인력 : 발견형 매장은 사람이 필요한데 마트는 인력 감축 중
  6 해외소싱 : 매대에 몇 SKU로 보이는가? 안 보이면 자산 아님
  7 데이터   : L.POINT가 상품 발주·PB 기획까지 붙었는가?

✕ 어긋나 있다   ← 여기가 핵심 (빨강)
  8 "최저가" 메시지 = 쿠팡의 잣대로 나를 잰다 → 깊이가 지워짐
  9 온라인과 마트가 따로 논다 → 활동이 서로를 못 키움
 10 제타플렉스급 소수 vs 노후 표준점 다수 → 같은 간판, 다른 약속
 11 버릴 것을 정한 적이 없다 → 트레이드오프 부재 ★★
```

> `[말로]` — "11번이 근본 원인입니다. 포터는 **전략의 본질은 무엇을 하지 않을지 정하는 것**이라고 했습니다.
> 롯데마트는 '무엇을 안 한다'를 선언한 적이 없습니다.
> 전 카테고리·전 가격대를 다 대응하니 자원이 얇게 퍼지고,
> 그래서 8·9·10번이 생깁니다. 8·9·10은 증상이고, 11이 병입니다."

## 2-5. 블록 [E] — 그래서 무엇을 할 것인가 (3가지)

전지에 쓸 것:

```
① 버릴 것을 먼저 선언한다
   "최저가 1등"은 포기 — 가격은 '납득 가능선' 방어까지만
   거기서 아낀 자원을 → 주류·신선·델리 깊이로 이전

② 전점 최소 약속선을 만든다
   깃발점포만의 가치는 브랜드가 아니다
   전 점포 공통 : 주류 코너 + 즉석조리 + 소분신선
   (점포 등급별로 '깊이'만 다르게, '방향'은 동일하게)

③ 활동을 한 고리로 잇는다
   칠성 소싱 → 보틀벙커 큐레이션 → 전문인력 →
   L.POINT 취향데이터 → 발주·PB 개발 → 다시 소싱

   KPI 교체 :  평당 매출  ✕
              주류·신선 고객의 연간 구매빈도  ○
```

> `[말로]` — "③의 마지막 줄이 실행의 핵심입니다.
> **평당 매출로 관리하면 천천히 둘러보는 발견형 매장은 반드시 죽습니다.**
> 지표를 안 바꾸면 위의 모든 이야기는 구호로 끝납니다."

## 4. 예상 반론과 답 (전지에 쓰지 말고 준비만)

| 반론 | 답 |
|---|---|
| "술은 카테고리가 너무 좁다" | 술 자체가 목적이 아니라 **온라인이 못 뺏는 앵커**입니다. 술 사러 온 고객이 안주·신선·델리를 같이 삽니다. 객단가와 방문빈도의 지렛대입니다. |
| "이마트도 와인 한다" | 합니다. 차이는 **그룹 안에 수입·유통사가 있느냐**입니다. 구색 확보 속도와 원가 구조가 다릅니다. `[칠성 주류 점유·수입 순위 확인필요]` |

| "노후 점포에 투자할 돈이 없다" | 그래서 **전점 리뉴얼이 아니라 최소 약속선**입니다. 주류 코너·즉석조리·소분신선 3가지만 표준화하는 건 전면 개보수보다 훨씬 쌉니다. |
