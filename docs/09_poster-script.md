# 09. 전지(全紙) 작성 스크립트 — 롯데마트 1번·2번

> 전지 1장을 세로선으로 좌/우 2단 분할. **왼쪽 = 1번, 오른쪽 = 2번.**
> 아래 【전지】 블록은 **그대로 옮겨 쓰는 용도**. 【설명】은 발표자 참고용 — 쓰지 않음.

# 【설명 — 발표자 참고용, 전지에 쓰지 말 것】

## 1번 블록 설명

**왜 '판단 기준'을 맨 위에 쓰는가**
이걸 안 걸면 토론이 "우리 마트 장점 찾기"로 흘러갑니다. 포터의 정의 — 유일한 가치란 *더 잘하는 것*이 아니라 *경쟁사가 따라 하면 자기가 벌던 걸 포기해야 하는 것*(트레이드오프)입니다. 기준을 먼저 걸면 아래 ✕/○ 분류가 자동으로 설득됩니다.

**✕ 항목을 왜 굳이 쓰는가**
사람들이 기대하는 답(가성비·신선·통합소싱)을 먼저 지워야 ○ 두 개가 살아납니다. 지우지 않으면 "그래도 우리 신선은 좋잖아요"에서 토론이 멈춥니다.
- 오카도는 애매한 케이스라 **"시한부 해자"** 로 설명하면 좋습니다. 한국 독점계약 기간엔 유일하지만, 계약이 끝나거나 경쟁사가 같은 기술을 사면 사라집니다. 자산을 산 것이지 자산을 만든 게 아닙니다.
- 통합소싱은 이마트가 에브리데이를 흡수합병하면서 같은 구조를 갖췄습니다. 질문 나오면 이걸로 답하세요.

**○ 두 개가 왜 진짜인가**
- 동남아: 이마트는 베트남 소수점·몽골 프랜차이즈, 홈플러스는 없음. **돈이 아니라 시간이 필요한 자산**이라 복제 불가.
- 그룹 제조: 신세계·홈플러스엔 식품 제조 계열이 없습니다. PB를 "남이 만든 걸 싸게 붙인 것"이 아니라 **"우리가 개발한 것"** 으로 만들 수 있는 건 롯데뿐입니다.

**마지막 ⚠ 가 이 블록의 핵심**
가장 강한 한 방입니다. "자산은 있는데 약속이 없다"는 건 곧 **아무것도 포기하지 않았다**는 뜻이고, 포터식으로는 전략이 없다는 말입니다. 반박이 들어오면: *"우리가 하지 않기로 한 것의 목록을 댈 수 있습니까?"* 로 되물으세요.

## 2번 블록 설명

**화살표 사슬로 그리는 이유**
불릿으로 나열하면 "활동 많네"로 끝나지만, **위에서 아래로 흐르는 사슬**로 그리면 *활동들이 서로를 강화한다*는 게 눈으로 보입니다. 이게 포터의 2차 적합성(reinforcement)입니다. 전지에 그릴 때 화살표는 굵고 크게.

**해외 사슬 각 단계 근거 (질문 대비)**
| 단계 | 사실 |
|---|---|
| 베트남 신규점 | 2026년 7월 떠이닌점, 영업면적 약 2,165㎡ 중 88%가 식품. 2023년 웨스트레이크 이후 3년 만의 출점 재개 |
| 인니 하이브리드 | 마타람점 1,400평 도매 → 1,000평 그로서리 소매 + 400평 도매. 매출 +60%, 고객 4배. 2년 7개월간 7곳 재단장 → 매출 +18%, 방문객 +64% |
| 요리하다 키친 | 개방형 주방+취식공간. 떡볶이·김밥·불고기도시락. 베트남 7점·인니 5점 |
| PB 수출 | 오늘좋은·요리하다 등 13개국 500여 품목. PB의 약 90%를 중소협력사가 생산 |
| 싱가포르 | NTUC 페어프라이스 숍인숍 'EXPRESS' 1호 비보시티(25.5)·2호 JEM(25.12), 전역 100여 매장에 PB 입점 |
| 배송·물류 | 스피드엘 앱(15km·3시간) + 그랩 제휴 1시간 배송, 베트남 물류센터 |
| 웨스트레이크 | 누적 매출 6,000억, 신장률 20%+. 2030년까지 초대형 몰 2~3개 추가 계획 |
| 기존점 전환 | 다낭·나짱점 그로서리 전환 후 매출 +31% |

**국내 ✕ 4줄이 왜 이 순서인가**
포지셔닝 → 채널 → 투자 → 사업범위 순으로, **점점 더 큰 결정**입니다. 마지막 "가전·패션·리빙 못 버림"이 가장 근본적인 문제 — 버린 게 없으니 트레이드오프가 없고, 그래서 1번의 ⚠ 와 연결됩니다.
- 오카도 CFC(부산·영남 400만 세대)와 점포 PP센터는 같은 상권 물량을 잠식합니다. 어느 쪽을 접을지 정하지 않으면 1조 투자의 규모의 경제가 안 나옵니다.

**결론 숫자를 크게 쓰는 이유**
△566억 / +496억 — 이 대비 하나가 2번 답 전체를 증명합니다. **"정합성의 차이"** 는 자간을 띄워 쓰면 시선이 멈춥니다. (2025년 실적 기준)

**마지막 질문의 의도**
토론을 닫지 말고 열어두는 장치입니다. 해외 활동 19개가 전부 *한국 것을 내보내는* 방향이고, 1번에서 선언한 약속의 절반 — **현지에서 소싱해 국내로 들여오는 역방향** — 이 비어 있습니다. 그게 없으면 밸류체인이 아니라 수출 사업입니다. 이 질문을 던지면 다음 토론 주제가 자연스럽게 생깁니다.

## 작성 실무 팁

- **비율**: 좌:우 = 4:6. 2번이 내용이 많습니다.
- **색 3개만**: 검정(본문) / 빨강(✕, △566억, ⚠) / 파랑(○, +496억, ▶). 4색 이상은 산만해집니다.
- **크기**: 제목 7~8cm, 소제목 4cm, 본문 2.5~3cm. 뒷줄에서 읽히는 하한이 2.5cm입니다.
- **먼저 연필로 가로줄**을 긋고 쓰면 줄이 안 기웁니다. 구분선(─────)은 자로.
- **숫자는 무조건 크게**: 48 / 16 / 88% / +60% / 6,000억 / △566억 / +496억. 사람은 숫자를 먼저 봅니다.
- 시간이 부족하면 **1번의 ⚠ 와 2번의 결론 숫자만은 반드시** 살리세요. 나머지는 말로 채울 수 있습니다.
