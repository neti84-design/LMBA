## Step 1. 가치 전달 영역 — "누구에게 무엇을?"

### 01 고객 세그먼트 | 우리의 타겟 고객은 누구인가?

| 우선순위 | 세그먼트 | 규모(가정) | 왜 이들인가 |
|---|---|---|---|
| **1차** | 롯데백화점·몰·아울렛에 팝업을 여는 브랜드 — 특히 정규 입점을 노리는 D2C·신생 브랜드 | 연 약 2,000건 `[검증필요]` | 성과 측정 니즈가 가장 절박하고, 계약 시점에 번들 판매 가능 |
| **2차** | 상설 입점 브랜드 매장 | 롯데 전 계열 매장 | 팝업 고객의 구독 전환 → 리커링 |
| **0차 (첫 고객)** | 롯데 내부 — 백화점 MD·영업관리·계열사 | — | 레퍼런스와 벤치마크 확보. 매출 0원, 대신 데이터 |
| 3차 | 외부 유통사, 해외 롯데몰(베트남·인도네시아) | — | Phase 3 이후 |

**고객의 Pain 3가지**
1. 팝업이 끝나면 손에 쥐는 건 **매출 총액과 인스타 해시태그 개수**뿐
2. 온 사람 중 **신규가 몇 %인지, 안 산 사람이 누구인지** 모름
3. 그래서 **다음 팝업도 감으로** 연다

### 02 가치 제안 | 고객의 어떤 문제를 해결해 주는가?

> **브랜드는 자기가 판 것만 압니다. 저희는 놓친 사람이 누구였는지 알려주고, 처방이 통했는지 POS로 증명합니다.**

**① 브랜드가 모르는 자기 고객 — 스스로는 절대 알 수 없는 5가지**
1. 이번에 온 사람 중 **신규가 몇 %인가**
2. 들어왔는데 **안 산 사람은 누구였나** (가격 미스매치? 타깃 오독?)
3. 우리 방문객이 **평소 어디서 무엇을 사는가** (경쟁 브랜드 교차구매)
4. **집었는데 안 산 상품** — 온라인 장바구니 이탈 = 상품기획 피드백
5. **다음 팝업은 어디에, 언제, 어느 층에**

**② 처방의 효과를 증명** — 개선안 제시 → 2~4주 적용 → **POS 전후 실측 비교**
(예: 집품→구매 전환율 8.1% → 11.4%). 경쟁사는 POS가 없어 이걸 못 합니다.

**③ 온라인 GA 지표의 오프라인 대응** — 노출→통행수, 클릭→유입률, 장바구니→집품률, 구매→전환율, 이탈→3초 이탈률

### 03 채널 | 고객에게 어떻게 접근하는가?

| 채널 | 방식 | 의미 |
|---|---|---|
| **영업 채널 (내부)** | 백화점 MD·영업관리팀이 **팝업 계약 체결 시 번들 제안** | 외부 영업비용 ≈ 0. 계약 시점 = 판매 시점 |
| **제품 채널** | L.GA 브랜드 포털(대시보드) + 팝업 종료 7일 내 **컨설턴트 리포트 미팅** | 리포트를 던지지 않고 설명한다 |
| **확산 채널** | 롯데 계열사(마트·하이마트·시네마·면세) → 해외 롯데몰 → 외부 유통사 | 안에서 밖으로 |
| **도달 채널 (고객의 고객)** | L.POINT 앱 푸시 · 사이니지 · 키오스크 | 인사이트를 실행(리타게팅)으로 |

### 04 고객 관계 | 어떻게 확보·유지·성장시킬 것인가?

| 단계 | 방법 | 핵심 장치 |
|---|---|---|
| **확보 (Acquire)** | Phase 0 롯데 내부 도입 → 파일럿 3건 무상 → 팝업 계약 번들 | 지불 의사를 가정하지 않고 **검증 후 과금** |
| **유지 (Retain)** | 효과 검증 리포트(POS 전후) · 월간 처방 리포트 · 전담 컨설턴트 | **증명이 갱신의 근거** — 리텐션 엔진 |
| **성장 (Grow)** | 팝업 → 상설 구독(정규 매장 오픈 시 첫 3개월 무료) → 컨설팅+성과연동 → 리타게팅 | 깔때기 업셀 |

### 05 수익원 | 고객은 무엇에 기꺼이 돈을 지불하는가?

| 상품 | 단가 | GM | 성격 |
|---|---|---|---|
| ① 팝업 솔루션 패키지 | ASP 320만원/건 (180/350/600) | 77% | 유입 |
| ② 상설 매장 구독 | 월 45만원/매장 | 84% | **리커링** |
| ③ 성장 컨설팅 + 성과연동 | 1,500만원/건 + 증분매출 5~10% | 73% | 고부가 |
| ④ L.POINT 리타게팅 | CPM/CPA | 60% | **리커링·레버리지** |

## Step 2. 효율적 운영 영역 — "어떻게 만들 것인가?"

### 06 핵심 자원 | 반드시 필요한 자산은?

| 유형 | 자원 | 비고 |
|---|---|---|
| **물리적** | 기존 CCTV·전원·네트워크·보안망 / 팝업존 보완 카메라(대당 ~25만원) / 엣지박스 점포당 1식(~300만원) | 신규 구축 대비 도입 기간·비용 대폭 절감 |
| **지적·데이터 ★** | **L.POINT 소비 이력 · POS 결제 · 전점 트래픽** / 카테고리 벤치마크 DB / 엣지 추론 모델 | **유일한 해자.** 벤치마크 DB는 시간으로만 쌓임 |
| **인적** | 리테일 컨설턴트 14 · DS/ML 8 · 애널리스트 8 · 개발 6 · 영업 4 · PO 2 (Y3 42명) | 컨설턴트 비중이 높은 이유: 처방·검증이 상품의 본체 |
| **금융** | 3년 CAPEX 11억 · 최대 현금소진 10억 · **파일럿 1.5억** | 롯데 기준 매우 가벼운 사업 |

### 07 핵심 활동 | 반드시 수행해야 하는 활동은?

| 유형 | 활동 | 누가 |
|---|---|---|
| **생산** | 엣지 추론(영상 미전송·원본 미저장) / 리포트 90% 자동 생성 | 시스템 |
| **문제해결** | 고객 인사이트 분석 → 개선 처방 → POS 전후 검증 | **사람(컨설턴트)** — 상품의 본체 |
| **플랫폼** | 벤치마크 DB 축적 / 리타게팅 운영 / 3사 데이터 결합 거버넌스 | 플랫폼 팀 |

**운영 원칙 — 프라이버시 2계층**: Layer 1(공간, 완전 익명) / Layer 2(고객, 앱 동의 기반) / 연결은 시간대×구역×세그먼트 **집계 단위로만**. 리포트에 개인은 등장하지 않습니다.

### 08 핵심 파트너 | 외부 파트너나 공급업체는 누구인가?

| 구분 | 파트너 | 제공하는 조각 |
|---|---|---|
| **내부 3사 합작** | 롯데백화점 | 공간 · 트래픽 · POS · MD 지식 |
| | 롯데이노베이트 | 비전 AI 엔진 · 엣지 인프라 |
| | 롯데멤버스 | L.POINT 소비 이력 · 도달 채널 |
| **외부** | 비전 AI 엔진 벤더 | 라이선스 또는 M&A — Build/Buy 병행 검토 |
| | 외부 VMD 디자이너 | 컨설팅 건당 변동비(400만원) |
| | 법무·DPO·개인정보 영향평가 | 착수 전 마일스톤 1번 |

> 세 조각이 다 모여야 성립하는 사업이고, 그래서 지금까지 아무도 못 했습니다.
