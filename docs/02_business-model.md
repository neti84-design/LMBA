# 02. 상품 설계와 수익모델 — "솔루션"을 판다

> 우리가 파는 것은 대시보드가 아닙니다.
> **① 무슨 일이 있었는지(리포트) ② 그 고객이 누구이고 무엇을 원하는지(인사이트)
> ③ 무엇을 바꿔야 하는지(처방) ④ 바꿨더니 통했는지(검증)** — 이 4단 솔루션입니다.

---

## 1. 상품 사다리 — 무엇을 제공하는가

| 단계 | 질문 | 산출물 | 롯데만 가능? |
|---|---|---|---|
| **L0 티저** `무상` | **어디에 열어야 하나** | **유입률 상위 스팟 3곳 + 평균 유입률·통행 패턴** | **예 ★★** (전점 트래픽이 있어야 가능) |
| **L1 측정** | 무슨 일이 있었나 | 통행·유입률·체류·동선·집품·전환 | 아니오 (메이아이도 가능) |
| **L2 진단** | 왜 그랬나 | 이탈 지점, 카테고리 벤치마크 대비 격차 | 부분 (벤치마크 규모 우위) |
| **L3 고객 인사이트** | **그 사람은 누구이고 무엇을 원하나** | **아래 §2 참조 — 핵심 차별화** | **예 ★★★** |
| **L4 처방** | 무엇을 바꿔야 하나 | VMD·동선·가격대·SKU·응대 개선안 | 부분 |
| **L5 검증** | **바꿨더니 통했나** | **개선 전후 POS 실측 비교** | **예 ★★★** |
| **L6 실행** | 그래서 고객을 어떻게 데려오나 | L.POINT 앱 쿠폰·리타게팅 발송 | **예 ★★** |

> **L3와 L5가 이 사업의 전부입니다.** L1·L2·L4만 하면 메이아이와 같은 회사가 됩니다.
> **L0는 그 사다리로 브랜드를 데려오는 입구**입니다.

---

### L0 티저 — 계약 전에 무상으로 여는 한 칸

브랜드가 우리에게 **가장 먼저 묻는 질문은 "어디에 열어야 하나"** 입니다.
그 답의 앞 세 줄만 계약 전에 무상으로 엽니다.

| 무상으로 공개 | 공개하지 않음 |
|---|---|
| 유입률 상위 스팟 **3곳** (점포·층·구역 단위) | 그 스팟의 **구매 전환율·객단가** |
| 해당 스팟의 **평균 유입률**, 카테고리 평균 대비 배수 | 방문객 **신규 비율 · 소비 프로파일** |
| 시간대·요일 **통행 패턴 요약** | **미구매자 분석 · 집품률 · 체류시간** |

- **공개선(線)의 기준**: 유입률·통행량은 **공간의 지표 = 롯데 자산**이라 우리가 열 수 있습니다.
  전환율·객단가는 **그 자리에 있던 브랜드의 성과**입니다. 계약 없이 공개하면 입점 브랜드의
  영업정보를 파는 셈이 됩니다. **이 선을 넘지 마십시오.**
- **집계 규칙**: 브랜드 1곳이 특정되는 전용 구역은 티저에서 제외하고,
  최근 4주 이상·**복수 브랜드 운영 이력**이 있는 구역만 씁니다.
- **나머지가 열리는 조건**: ① 팝업 패키지 구매 · ② 상설 매장 구독 · ③ 해당 매장에서 L.GA 운영 중
- **목적은 매출이 아니라 계정 확보**입니다. 구글 애널리틱스가 무료인 것과 같은 구조 —
  측정의 앞 한 칸을 열어 브랜드를 데려오고, 돈은 ③~⑤에서 법니다.

> **발표 한 줄**: *"유입률은 공간의 지표라 공개할 수 있고, 전환율은 그 브랜드의 성과라 계약 안에서만 열립니다."*

## 2. ★ 핵심 상품: 「브랜드가 모르는 자기 고객」 리포트

브랜드의 자체 데이터는 자사 POS에서 끝납니다. 즉 **"산 사람이 산 것"** 만 압니다.
L.POINT 소비 이력과 전점 트래픽을 결합하면 그 바깥을 보여줄 수 있습니다.

| 제공 항목 | 브랜드가 얻는 것 | 브랜드가 스스로 알 수 있나 |
|---|---|---|
| **신규 vs 기존 고객 비율** | 이번 팝업이 신규 획득을 했는지, 기존 고객만 다시 온 건지 | ❌ 불가 |
| **방문객 소비 프로파일** | 우리 고객의 소비력·선호 카테고리·라이프스테이지 | ❌ 불가 |
| **경쟁 브랜드 교차구매** | "우리 방문객의 38%가 A브랜드 구매 이력" → 포지셔닝·가격 전략 | ❌ 불가 |
| **미구매자 분석** | 들어왔는데 안 산 사람은 누구였나 → 가격 미스매치인가 타깃 오독인가 | ❌ 불가 |
| **집품됐지만 안 팔린 SKU** | 온라인의 '장바구니 이탈'에 해당 → **상품기획 직접 피드백** | ❌ 불가 |
| **유입 경로·전후 동선** | 어느 층·어느 매장을 거쳐 왔고 다음에 어디로 갔나 | ❌ 불가 |
| **차기 출점 처방** | 다음 팝업은 어느 점포·어느 층·어느 시기에 여는 게 최적인가 | ❌ 불가 |

> ⚠️ 모든 항목은 **개인 단위가 아니라 세그먼트·집계 단위**로 제공합니다 (`01_gap-analysis.md` GAP 1).
> "김OO씨가 왔다"가 아니라 **"20대 후반·뷰티 고관여·월평균 객단가 상위 30% 세그먼트가 42%"** 입니다.

**발표 한 줄**: *"브랜드는 자기가 판 것만 압니다. 저희는 그들이 놓친 사람이 누구였는지 알려줍니다."*

---

## 3. ★ 두 번째 무기: 처방의 효과를 증명한다 (L5)

컨설팅은 **효과를 증명해야 재구매**됩니다.

```
개선안 제시 (L4)  →  2~4주 적용  →  POS 실측 비교 (L5)
                                    "집품→구매 전환율 8.1% → 11.4% (+3.3%p)"
```

- 메이아이는 **POS 데이터가 없어 자기 처방의 효과를 증명할 수 없습니다.** 리포트에서 끝납니다.
- 우리는 증명할 수 있으므로 **① 재계약이 발생하고 ② 성과연동 과금이 가능**해집니다.
- 이것이 리텐션 엔진이자 가격 결정력의 원천입니다.

## 4. 수익모델 — 5단 구조

```
┌──────────────────────────────────────────────────────────────┐
│ ① 팝업 솔루션 패키지  (리포트 + 고객 인사이트 + 개선 처방)      │
│    180 / 350 / 600만원 · ASP 320만원 · GM 77%                 │
└──────────────┬───────────────────────────────────────────────┘
               │ 지속 관리 니즈
┌──────────────▼───────────────────────────────────────────────┐
│ ② 상설 매장 구독 (월간 처방 리포트 + 대시보드)  리커링①        │
│    월 45만원/매장 · GM 84%                                     │
└──────────────┬───────────────────────────────────────────────┘
               │ 심층 니즈
┌──────────────▼───────────────────────────────────────────────┐
│ ③ 성장 컨설팅 (VMD·상품기획·출점전략) + 성과연동 수수료          │
│    건당 1,500만원 + 증분매출 5~10% · GM 73%                     │
└──────────────┬───────────────────────────────────────────────┘
               │ 데이터 축적
┌──────────────▼───────────────────────────────────────────────┐
│ ④ 고객 도달 실행 — L.POINT 리타게팅 (RMN)   리커링② · 레버리지  │
│ ⑤ 카테고리 벤치마크 데이터 라이선스          리커링③ · GM 90%   │
└──────────────────────────────────────────────────────────────┘
```

### ① 팝업 솔루션 패키지

| 등급 | 가격 | 구성 |
|---|---|---|
| **Basic** | 180만원 | L1 측정 — 유입률·체류·성별연령·종료 리포트 |
| **Standard** | 350만원 | + L2 진단(벤치마크 대비) + **L3 고객 인사이트** + L4 개선 처방 |
| **Premium** | 600만원 | + 전관 동선 · 미구매자 심층분석 · 상품기획 피드백 · **차기 출점 처방** · 앱 쿠폰 1회 |

- ASP **320만원** / 건당 변동비 약 **75만원**(설치 35 + 장비감가 5 + 추론 3 + 인사이트 분석·리포트 검수 25 + 기타 7) → **GM 77%**
- 목적: 이익이 아니라 **계정 확보와 데이터 축적**. 가격을 올리지 마십시오.

### ② 상설 매장 구독 — 리커링 ①
- **월 45만원/매장**. 단순 대시보드 열람이 아니라 **월간 처방 리포트 + 분기 검증 리포트** 포함
- 매장당 월 변동비 약 7만원 → **GM 84%**
- 전환 동선: 팝업 Standard 이상 구매 브랜드 → 정규 매장 오픈 시 **첫 3개월 무료** 번들

### ③ 성장 컨설팅 + 성과연동 — 고부가
- 건당 **1,500만원** (4~6주). 산출물: 개선안 + **적용 후 POS 검증 리포트**
- 범위: VMD·동선 / 가격대·SKU 구성 / 응대 시나리오 / **차기 출점·팝업 전략**
- 건당 변동비 약 400만원(외부 VMD 디자이너·현장 실사·분석 공수) → **GM 73%**
  *(내부 컨설턴트 인건비는 판관비에 별도 계상 — 이중계상 아님)*
- **성과연동 수수료**: 검증된 증분 매출의 **5~10%** → L5가 있어야만 가능한 과금 방식

### ④ L.POINT 리타게팅 (RMN) — 리커링 ②
> 인사이트의 **실행 버전**입니다. "이런 고객이 왔었다"에서 끝내지 않고 **다시 불러옵니다.**

- 상품: **매장 앞을 지나갔지만 들어오지 않은 세그먼트 / 들어왔지만 안 산 세그먼트에게 L.POINT 앱 쿠폰 발송**
- 인벤토리: L.POINT 앱 푸시 · 백화점 사이니지 · 엘리베이터 디스플레이 · 키오스크
- 과금 CPM/CPA, 매체원가 약 40% → **GM 60%**
- **통행 데이터와 고객 도달 채널을 동시에 가진 사업자만** 만들 수 있는 상품

### ⑤ 카테고리 벤치마크 라이선스 — 리커링 ③
- "2026 상반기 K-뷰티 팝업 벤치마크" 형태의 정기 리포트
- 구매자: 브랜드사, 컨설팅펌, VC/PE, 리서치사 / 연 2,000~5,000만원 / **GM 90%**
- 데이터가 쌓일수록 가치 상승 → **시간이 만드는 해자**

## 5. 가격·수익성 요약

| 상품 | 단가 | GM | 성격 |
|---|---|---|---|
| ① 팝업 솔루션 패키지 | ASP 320만원/건 | 77% | 유입 (비리커링) |
| ② 상설 매장 구독 | 45만원/월·매장 | 84% | **리커링** |
| ③ 성장 컨설팅 | 1,500만원/건 + 성과연동 | 73% | 고부가·재구매 |
| ④ L.POINT 리타게팅 | CPM/CPA | 60% | **리커링·레버리지** |
| ⑤ 벤치마크 라이선스 | 2,000~5,000만원/년 | 90% | **리커링·해자** |

**블렌디드 매출총이익률 약 77%**, 3년차 영업이익률 **35%** (상세: `03_financials.md`)
3년차 기준 **리커링 매출 비중 51%** — 팝업은 매출 엔진이 아니라 **유입 깔때기**입니다.

## 6. 【별도】 롯데 내부 귀속 가치 `[검증필요]`

외부 매출과 별개로 롯데가 직접 얻는 이익. 발표 시 1장 할애 권장.

| 항목 | 메커니즘 |
|---|---|
| 팝업 임대료 다이나믹 프라이싱 | 실측 통행량 기반 구역 등급제 → 프라임존 가격 차등화 |
| MD 브랜드 선별 고도화 | 팝업 성과 데이터로 정규 입점 브랜드 검증 → 조기 철수·재계약 실패 감소 |
| 면적당 매출 최적화 | 층별·구역별 배치 재설계 |
| 비구매 트래픽의 자산화 | 버려지던 통행 데이터 → 광고 인벤토리 |

> ⚠️ 정규 입점 연계는 **브랜드에게 제공하는 여러 가치 중 하나이자 롯데 내부 효익**으로만 다루십시오.
> 메인 메시지로 올리면 "백화점 입점 장사"로 읽혀 솔루션 가치가 흐려집니다.
