# 02. 수익모델 재설계 — 4단 수익구조

> 기존 안: 팝업 패키지(150~300만) + 상설 SaaS + 컨설팅 → **연 40억 수준의 천장**
> 재설계 안: 위 3개 + **리테일미디어(RMN) + 데이터 라이선스** → **3년 내 연 100억 + 내부 귀속가치**

---

## ① 팝업 패키지 — 유입 상품

| 등급 | 가격 | 구성 |
|---|---|---|
| **Basic** | 150만원 | 카메라 2대 · 유입/체류/성별연령 · 종료 리포트 |
| **Standard** | 280만원 | + 구역별 히트맵 · 집품률 · L.POINT 세그먼트 · 카테고리 벤치마크 대비 |
| **Premium** | 450만원 | + 실시간 대시보드 · 백화점 전관 동선(어디서 와서 어디로 갔나) · 미입장 고객 앱 쿠폰 1회 |

- 목표 평균단가(ASP): **280만원**
- **건당 변동비 약 65만원** → 설치 인건비 35만 / 장비 감가 5만 / 추론·클라우드 3만 / 리포트 검수 15만 / 기타 7만
- **매출총이익률 약 77%**

> 이 상품의 목적은 이익이 아니라 **계정 확보와 데이터 축적**입니다. 가격을 올리지 마십시오.

---

## ② 상설 매장 SaaS — 리커링 ①

- **월 35만원 / 매장** (연간 계약, 연납 시 10% 할인)
- 대상: 롯데백화점·몰 입점 브랜드 매장, 롯데 직영 매장, 계열사 매장
- 매장당 월 변동비 약 5만원 (엣지박스 감가 + 메타데이터 처리 + 지원) → **GM 약 86%**
- 도입 유인: 팝업 성과 리포트를 본 브랜드에 **정규 입점 시 첫 6개월 무료** 번들

---

## ③ VMD·입점 컨설팅 — 고부가

- **건당 1,500만원** (4~6주 프로젝트)
- 산출물: 구역별 매출기여도 분석 → **진열·동선·사이니지 개선안** → 개선 후 A/B 검증 리포트
- 프리미엄 옵션: **정규 입점 제안서 패키지** (예상 매출 추정 + MD 심사 제출용)
- 건당 변동비 약 400만원(컨설턴트 공수) → **GM 약 73%**
- 옵션: 개선 후 증분 매출의 **5~10% 성과 수수료(Success Fee)** 병행

---

## ④ 리테일미디어(RMN) + 데이터 라이선스 — 최대 레버리지

### 4-1. 오프라인 리타겟팅 광고
> **"팝업 앞을 지나갔지만 들어오지 않은 고객에게, L.POINT 앱 쿠폰을 보낸다."**

- 인벤토리: 백화점 사이니지 · 엘리베이터/에스컬레이터 디스플레이 · **L.POINT 앱 푸시** · 키오스크
- 과금: CPM(노출) / CPA(쿠폰 사용) / 성과연동
- 매체 원가(정산·리워드) 약 40% → **GM 약 60%**
- **핵심**: 통행 데이터(Layer 1)와 고객 도달 채널(Layer 2)을 **동시에 가진 사업자만** 만들 수 있는 상품.
  메이아이도, 구글도 만들 수 없습니다.

### 4-2. 데이터 라이선스 (닐슨 모델)
- 카테고리별 **오프라인 벤치마크 리포트** 정기 판매
  (예: "2026 상반기 K-뷰티 팝업 벤치마크 — 평균 유입률·체류·전환")
- 구매자: 브랜드사, 컨설팅펌, VC/PE(투자 심사용), 리서치사
- 연 구독 2,000~5,000만원 / GM 약 90%
- **데이터가 쌓일수록 상품 가치 상승 → 후발주자 진입 불가**

| 항목 | 메커니즘 | 효과(가정) |

| 팝업 임대료 다이나믹 프라이싱 | 실측 통행량 기반 구역 등급제 → 프라임존 가격 인상 | 팝업 임대수익 **+5~10%** |
| MD 입점 실패율 감소 | 데이터 검증 브랜드만 정규 입점 | 조기 철수·재계약 실패 감소 |
