# 08. 전지 작성안 — 「해외 점포망」 한 축으로 쓰는 롯데마트 전략 진단

> **전지 1장 (788×1091mm, 가로로 눕혀서) · 가운데 세로선으로 좌우 2단**
> **왼쪽 = 유일한 가치 (해외 점포망) · 오른쪽 = 활동은 그대로 짜여 있는가**
>
> 유일한 가치를 **해외 점포망 하나로만** 좁혔습니다.
> 여러 개를 나열하면 "그래서 뭐가 제일 유일한데"라는 질문에 무너집니다. 하나로 갑니다.

# 왼쪽 단 — 롯데마트가 유일하게 줄 수 있는 것

## [L0] 제목

```
Q1.  롯데마트만 가진 것
     = 해 외  점 포 망

     남들은 수입한다.
     롯데는 현지에서 판다.
```

## [L1] 경쟁자 한 줄 비교

```
  이마트     중국 철수 · 베트남 파트너 전환
  홈플러스    해외 점포 없음
  코스트코    글로벌 본사 소싱
             한국 협력사 판로는 아님
  쿠팡·컬리   오프라인 점포 자체가 없음
 ───────────────────────────
  롯데마트    베트남 · 인도네시아
             직영 점포망          ★
```

> `[말로]` — "한국 대형마트 중 해외에서 **직접 점포를 운영하는 곳은 롯데마트뿐**입니다.
> 이마트는 중국에서 철수했고 베트남도 파트너 체제로 바꿨습니다.
> 이건 돈이 있다고 1~2년에 만들 수 있는 게 아닙니다. **점포는 10년이 걸립니다.**"
> `[점포 수·현지 법인 형태는 발표 전 확인필요]`

## [L2] 그 점포망이 만드는 것 — 4개

```
 ① 산지 직소싱
    중간 수입상을 건너뛴다
    → 원가 · 신선도 · 남들 없는 구색

 ② 협력사에게 줄 수출 판로
    "우리와 하면 해외 매대에 깔린다"
    → 좋은 상품이 롯데에 먼저 온다

 ③ PB 생산 · 조달 기지
    요리하다 · 오늘좋은의 원가 방어

 ④ 성장하는 두 번째 시장
    국내는 규제 · 역성장
    현지는 젊은 인구 · 중산층 확대
```

> `[말로]` — "네 개 중 **②가 가장 과소평가된 자산**입니다.
> ①③④는 롯데가 얻는 이익이지만, ②는 **협력사에게 주는 이익**입니다.
> 경쟁사는 줄 수 없는 조건이라, **국내 상품 협상 테이블에서 그대로 힘이 됩니다.**
> 좋은 상품을 누가 먼저 가져가느냐 — 그게 마트 경쟁의 시작점입니다."

## [L3] 결론 (빨강, 가장 크게)

```
  수입하는 회사가 아니라
  현지에서 파는 회사

  → 돈으로 못 따라온다
```

## [L4] 다리 놓기 (작게, 검정)

```
  단, 한국 고객은
  인도네시아 점포를 모른다.

  매대 위 상품으로 바뀌어야
  비로소 "가치"가 된다   ──→
```

# 오른쪽 단 — 활동은 그 강점대로 짜여 있는가

## [R0] 제목

```
Q2.  그 강점대로
     활동이 짜여 있는가

     자산은 있다.
     사슬이 문제다.
```

## [R1] 활동 사슬 그림

네모 상자를 화살표로 잇습니다. **한 줄 사슬 + 아래에서 합류하는 가지 1개.**

```
  해외점포 ─→ 현지바잉 ─→ 물류·콜드체인
      │
      └─→ 국내매대 ─→ 고객체감 ─→ 재구매
                ↑
        협력사 수출판로 ─→ 국내 바잉협상력

  ※ 끊긴 지점에 빨간 가위표(✂)를 그린다
     → "국내매대 → 고객체감" 구간에 ✂
```

> `[말로]` — "사슬을 그려보면 어디가 끊겼는지가 한눈에 보입니다.
> 앞쪽 절반(해외점포·현지바잉·물류)은 돌아갑니다.
> **끊긴 건 '국내 매대 → 고객 체감' 구간입니다.**"

## [R2] 신호등

```
○ 맞물려 있다
  · 해외 점포 운영 = 소싱 인프라가 실재
  · 마트+슈퍼 통합구매
    = 컨테이너 물량을 소화할 국내 볼륨
  · PB 2종 정리
    = 해외 조달을 담을 그릇이 있다

△ 절반만
  · 소싱 성과를 SKU·매대로 관리하는가
  · 콜드체인 리드타임 (신선의 실질 제약)

✕ 어긋나 있다          ← 핵심 (빨강)
  · 매대에서 안 보인다
    → 그냥 싸 보이는 바나나일 뿐
  · 수출 판로를 협상 카드로 안 쓴다
  · KPI가 분리돼 있다
    해외는 현지실적 / 국내는 국내실적
    → 아무도 "연결"로 평가받지 않는다
  · 국내 최저가 경쟁에 자원이 쏠린다
    직소싱은 리드타임이 길다 → 밀린다
```

> `[말로]` — "✕ 세 번째가 근본 원인입니다.
> **활동이 안 이어지는 건 의지 문제가 아니라 평가 지표 문제입니다.**
> 해외본부는 현지 손익으로, 국내본부는 국내 손익으로 평가받습니다.
> 그러면 '해외 자산을 국내 매대로 옮기는 일'은 **누구의 성과도 아닙니다.**
> 아무의 성과도 아닌 일은 조직에서 일어나지 않습니다."

## [R3] 판정 (빨강, 가장 크게)

```
  자산은 유일한데
  가치로 번역하는 고리가 끊겼다

     사슬 정합성 :  55 / 100
```

## [R4] 그래서 셋

```
 ① 번역한다
    전점 「글로벌 직소싱 존」
    + 상품에 산지·경로 표기
    → 고객이 5분 안에 체감

 ② 지표를 교차시킨다
    해외본부 ← "국내 매대 기여"
    국내본부 ← "직소싱 비중"
    → 사슬을 잇는 유일한 실무 수단

 ③ 무기로 쓴다
    협력사 등급에
    "롯데 해외 채널 입점 우선권"
    → 좋은 상품이 먼저 온다
```

## 2. 발표 대본 (전지 앞에서 3분)

**왼쪽 (90초)**

1. (제목 짚고) "유일한 가치를 찾을 때 기준은 하나로 잡았습니다. **경쟁자가 돈을 써도 못 따라오는가.**"
2. (경쟁자 줄 짚고) "해외에서 직접 점포를 운영하는 한국 마트는 롯데뿐입니다. 이마트는 중국에서 나왔습니다."
3. (①②③④) "이 점포망이 네 가지를 만듭니다. 산지 직소싱, 협력사 수출 판로, PB 조달 기지, 두 번째 성장 시장."
4. (②에 손 얹고) "가장 과소평가된 건 둘째입니다. **경쟁사가 협력사에게 줄 수 없는 조건**이고, 그게 국내 협상력으로 돌아옵니다."
5. (빨강 결론) "**수입하는 회사가 아니라 현지에서 파는 회사입니다.** 점포는 10년이 걸립니다."
6. (L4 짚고) "그런데 — 한국 고객은 이걸 모릅니다. 그래서 오른쪽 질문이 진짜 질문입니다."

**오른쪽 (90초)**

1. (사슬 그림) "활동을 사슬로 그려봤습니다. 앞쪽 절반은 돌아갑니다."
2. (✂ 표시) "**끊긴 건 국내 매대에서 고객이 체감하는 구간입니다.** 산지 직소싱 상품인지 아무도 모르면, 그냥 싼 바나나입니다."
3. (○ 칸) "맞물린 것도 있습니다. 마트·슈퍼 통합 구매 덕에 컨테이너 단위 물량을 소화할 국내 볼륨이 있습니다. 이건 직소싱의 전제조건입니다."
4. (✕ 세 번째) "근본 원인은 지표입니다. **해외 자산을 국내 매대로 옮기는 일이 누구의 성과도 아닙니다.**"
5. (판정) "그래서 판정은 이렇습니다. **자산은 유일한데, 가치로 번역하는 고리가 끊겼다.**"
6. (셋) "번역하고, 지표를 교차시키고, 협상 무기로 씁니다. **②번 하나만 해도 나머지는 따라옵니다.**"

## 3. 예상 반론과 답 (전지에 쓰지 말고 준비만)

| 반론 | 답 |
|---|---|
| "해외 점포는 적자 아닌가" | 손익과 전략 자산은 다른 질문입니다. 여기서 쓰는 가치는 **현지 이익이 아니라 소싱권과 판로**입니다. 다만 현지 손익은 별도로 방어해야 하고, ②번 교차 KPI가 그 명분을 만듭니다. `[현지 법인 손익 확인필요]` |
| "직소싱은 이마트도 한다" | 합니다. 차이는 **벤더를 통해 사느냐, 우리 점포가 현지에 있느냐**입니다. 현지 운영 경험·인허가·현지 네트워크가 소싱 조건을 바꿉니다. |
| "고객은 산지에 관심 없다" | 가격만 볼 때는 그렇습니다. 그래서 ①번이 '산지 표기'가 아니라 **매대 구성(직소싱 존)** 입니다. 표기는 정보고, 존은 경험입니다. |
| "수출 판로는 마트 일이 아니다" | 상생 활동으로 보면 그렇습니다. **상품 확보 수단으로 보면 마트의 핵심 업무**입니다. 좋은 상품을 먼저 가져오는 것이 마트 경쟁의 출발점입니다. |
| "KPI 교차는 현실적으로 어렵다" | 어렵습니다. 그래서 **전면 개편이 아니라 지표 한 줄 추가**입니다. 해외본부 평가에 "국내 매대 기여" 한 줄, 국내본부에 "직소싱 비중" 한 줄. |
