## 홈페이지의 CCTV 띠와 실제 영상

히어로 바로 아래 가로 띠는 캔버스로 그리는 시뮬레이션입니다. 사람이 매장 앞을 지나가고, 경계선을 넘어 들어오고, 집기 앞에 머물다 상품을 집는 과정을 익명 박스가 따라갑니다. 실루엣과 번호만 그리며 얼굴이나 성별·연령 추정값은 표시하지 않습니다.

띠를 클릭하면 실제 영상이 재생됩니다. 영상 파일을 `site/media/cctv.mp4` 에 두십시오. 파일이 없으면 안내문이 대신 뜹니다. 단일 파일 버전에서는 영상이 파일 안에 들어 있지 않으므로 안내문만 보입니다.

## 유입률 상위 스팟 섹션 (`#spots`)

핵심 숫자 바로 아래, 페이지 상단에 **유입률이 높은 스팟 세 곳을 계약 전에 무상으로** 보여주는 섹션입니다.
공개하는 선을 지표의 소유자로 갈랐습니다.

- **공개**: 스팟명(점포·층·구역), 평균 유입률, 카테고리 평균 대비 배수, 일 평균 통행량, 유입 피크 시간대
- **비공개**: 구매 전환율·객단가, 신규 비율, 미구매자 프로파일, 집품률·체류시간 — 카드 안에서 `■ ■ %` 로 가려 둡니다
- **근거**: 유입률·통행량은 **공간의 지표(롯데 자산)**, 전환율·객단가는 **그 자리에 있던 브랜드의 성과**입니다
- **여는 조건**: 팝업 솔루션 패키지 · 월 구독 · 해당 매장에서 L.GA 운영

스팟 수치를 고치려면 `index.html` 의 `<section class="spots">` 안 카드 세 개를 직접 수정하면 됩니다.
발표자료의 같은 내용은 7번 슬라이드(`deck/build.js`)와 `docs/02_business-model.md` 「L0 티저」에 있습니다.

## 계정 없이 공유하려면

**[`LGA_시안_단일파일.html`](LGA_시안_단일파일.html)** 한 개면 됩니다. 위 3개 페이지가 전부 이 파일 안에 들어 있고, 페이지 사이 이동도 그대로 됩니다. 카카오톡·이메일로 이 파일 하나만 보내면 받는 사람이 더블클릭해서 바로 봅니다. 설치도, 로그인도, 인터넷도 필요 없습니다 (인터넷이 없으면 글꼴만 시스템 기본으로 대체됩니다).

파일을 다시 만들려면 `site/`에서 3개 페이지를 수정한 뒤 빌드 스크립트를 다시 돌리면 됩니다 (커밋 기록 참조).

## 디자인 원칙

- 발표자료(`deck/design.js`)와 같은 팔레트: 잉크 `#0E1420`, 롯데 레드 `#E11D2E`, 슬레이트 `#5E6979`. 글꼴은 Pretendard 우선, 없으면 Noto Sans KR(Google Fonts), 라벨·숫자는 IBM Plex Mono.
- 차트 색은 롯데 레드를 쓰지 않습니다. 데이터 계열은 파랑/주황(색각 검증된 조합), 퍼널은 파랑 단색 램프.
- 라이트/다크 모드 모두 지원 (`prefers-color-scheme` + `data-theme`).
- 모든 인사이트 문구는 `docs/02_business-model.md` §2 「브랜드가 모르는 자기 고객」 항목과 1:1로 대응합니다.

## 수치에 대한 경고

홈페이지·포털·리포트의 브랜드, 점포, 통행·전환·매출 수치는 **모두 가상의 예시**입니다. `#spots` 섹션의 스팟명과 유입률도 마찬가지입니다 — 실제 공개 전에 해당 월 실측값으로 바꾸고, 구역 단위 통행 데이터를 대외 공개해도 되는지 먼저 확인해야 합니다 (`docs/06_action-plan.md` A8). 리포트 안의 숫자는 서로 맞아떨어지도록 설계했지만(퍼널 → 일별 합계 → SKU 합계 → 주차별 검증), 실제 롯데 내부 데이터가 아닙니다. 발표 시 "예시 리포트"임을 반드시 언급하십시오.

## 수정 방법

- 홈페이지 문구·요금: `index.html` 안의 해당 섹션 텍스트를 직접 수정.
