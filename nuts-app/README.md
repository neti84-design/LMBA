# 넛츠 NUTS — 앱 프로토타입 (강남구)

> 지금, 비어 있는 예약 한 자리를 — 내가 갈 수 있는 거리 안에서.
> `넛츠_사업정리.docx` (IR 덱 10장 기준 · 2026. 09) 의 코어 메커니즘을 그대로 화면으로 옮긴 프로토타입입니다.

## 실행

```bash
cd nuts-app
node server.js            # → http://localhost:8787   (의존성 없음, Node 18+)
# 또는 저장소 루트에서:  npm run app
```

파일을 그냥 더블클릭해도 열립니다 (`index.html`). 폰에서 보려면 같은 와이파이에서 `http://<PC IP>:8787`.

## 네이버 플레이스 연동

매장 정보의 원천은 네이버 플레이스입니다. 두 단계로 동작합니다.

| 상태 | 동작 |
|---|---|
| 키 없음 (기본) | `data/stores.js` 시드 사용. 레코드의 `naver` 블록은 **네이버 지역검색 API 응답과 같은 필드**(`address` · `roadAddress` · `telephone` · `category`)로 적혀 있고, 매장마다 "네이버 플레이스에서 보기" 링크가 붙습니다. |
| 키 있음 | `NAVER_CLIENT_ID=… NAVER_CLIENT_SECRET=… node server.js` → `/api/naver/local` 이 실제 지역검색 응답을 돌려주고 `lib/naver-place.js` 가 같은 형태로 정규화합니다. |

키 발급: [developers.naver.com](https://developers.naver.com) → 애플리케이션 등록 → **검색** API.
지역검색 API는 평점·리뷰 수를 주지 않습니다 (플레이스 페이지에서만 노출). 그래서 실데이터 모드에서는 평점 자리에 "네이버 플레이스 정보" 링크만 보입니다.

> ⚠ 시드의 상호·가격·리뷰 수는 **프로토타입용 샘플**입니다. 동·도로명은 실제 강남구 지리를 따르지만 상호는 가상입니다.
> 롯데 파트너 2곳(롯데시네마 브로드웨이(신사) · 롯데백화점 강남점 문화센터)은 실제 장소이지만 상영·좌석·가격은 예시값입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 마크업 · 스타일 — 컨셉 시안 팔레트(크림 `#FBF5EA` · 브라운 `#4A2A12` · 오렌지 `#E8622A` · 그린 `#6C8A3A`). 핀 로고 속 땅콩은 [brand/nuts-mark.svg](../brand/nuts-mark.svg) 원본 패스, 워드마크 글꼴은 브랜드와 같은 Black Han Sans |
| `app.js` | 가격 엔진 · 도달 가능성 · 일러스트 지도 · 화면 라우팅 |
| `data/stores.js` | 강남구 시드 (매장 22 + 롯데 2 + 보물 카페 5) · 지도 도로/역 좌표 |
| `lib/naver-place.js` | 네이버 지역검색 응답 정규화 · 플레이스/길찾기 링크 |
| `server.js` | 정적 서버 + 네이버 API 프록시 |
| `assets/` | 컨셉 시안에서 잘라낸 마스코트 · 히어로 · 로고 |

지도는 외부 타일 없이 강남구 주요 도로·역·녹지를 근사 좌표로 그린 **일러스트 지도**입니다 (컨셉 시안의 부드러운 지도 톤). 실서비스에서는 네이버 지도 SDK로 교체하면 됩니다.
